# Educational Malware Simulation

## Objective
Simulate a harmless cybersecurity scenario.

## PC 1 - Attacker
- Prepare the simulation.
- Publish the project on GitHub.
- Share the repository.

## PC 2 - Victim
- Receive the project.
- Inspect the source code.
- Analyze simulation results.
- Detect suspicious indicators.

## Safety
- No real malware.
- No data theft.
- No reverse shell.
- No system damage.
